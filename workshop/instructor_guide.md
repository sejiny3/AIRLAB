## 2. 실습 코드 배포

### 저장소 만들기

이 폴더(`UNBOLT/`) 전체가 학생이 받는 저장소입니다. `third_party/`(OpenArm 모델, 약 280 MB)는 **넣지 않습니다**.
설치 스크립트가 고정 커밋으로 받습니다.

```bash
$ cd ~/unbolt     # 또는 강사가 작업한 폴더
$ git init -b main
$ git add -A && git commit -m "UNBOLT workshop materials"
$ git remote add origin https://github.com/<계정>/unbolt.git
$ git push -u origin main
$ git tag workshop-2026 && git push origin workshop-2026     # 강습회 당일 버전 고정
```

`.gitignore`가 `build/ install/ log/ third_party/`를 제외하고, `.gitattributes`가 `*.sh`를 LF로 고정합니다
(Windows에서 ZIP으로 받아도 `$'\r'` 오류가 덜 나게).

- 저장소를 공개하기 전에 **API 키·개인 정보가 없는지** 확인: `git grep -n "sk-ant-"` 결과가 비어 있어야 함
- OpenArm 모델은 Apache-2.0입니다. 저장소 README에 출처를 남겨 두었습니다.
- 학생이 GitHub 계정이 없어도 **Code → Download ZIP**으로 받을 수 있습니다 (설치 가이드 3장 방법 B).

### 버전 고정

| 구성 | 고정 방법 |
|---|---|
| ROS 2 패키지 | apt (Humble은 2027년 5월까지 지원). 강습회 직전 `apt upgrade`로 깨지는 경우가 드물게 있으니 D-1에 강사 노트북도 `upgrade` 후 리허설 |
| MuJoCo, anthropic | `install_unbolt.sh`의 pip 버전 (`mujoco==3.12.0`, `anthropic==2.3.0`) |
| OpenArm 모델 | `install_unbolt.sh`의 `OPENARM_*_COMMIT` |
| Claude 모델 | `task_planner_core.py`의 `MODEL = 'claude-opus-5-5'` |

## 4. API 키와 비용

모듈 4에서 Claude(`claude-opus-5-5`)를 부릅니다. 명령 하나에 Claude 호출이 도구 수만큼(보통 5~7번) 일어나고,
`ask`가 명령마다 실제 토큰과 비용을 출력합니다. **리허설 때 최종 미션 명령의 비용을 재서** 아래 표를 채우세요.

| 항목 | 값 |
|---|---|
| 가격 (2026년 10월 기준) | 입력 $4 / 출력 $20 (100만 토큰당) |
| 최종 미션 명령 1회 | 리허설 실측: ____ 토큰, 약 $____ |
| 학생 1명이 모듈 4에서 쓰는 양 | 명령 20~40회 정도 |

운영 방식 (하나 고르기):

| 방식 | 장점 | 주의 |
|---|---|---|
| **A. 학생 각자 발급** | 관리 부담 없음 | 가입·결제 장벽. 사전 공지에 [설치 가이드 7장](00_install.md#7-claude-api-키-모듈-4-전까지-선택) 링크 |
| **B. 강사가 발급해 나눠 줌** | 당일 바로 사용 | Console에서 **강습회 전용 Workspace**를 만들고 Workspace 월 한도를 걸기. 학생별 키를 만들어 이름을 붙이면 누가 얼마 썼는지 보임. **강습회 끝나면 키 전부 삭제** |
| **C. 키 없이** | 비용 0 | `llm:=scripted`(정해진 순서 재생)로 로봇 쪽만. 최종 미션은 강사 화면으로 시연 |

B의 키 배포: 종이 쪽지나 개별 DM. 단체 채팅방에 올리지 마세요 (유출되면 모두의 한도를 씁니다).
학생은 키를 `setup_api_key.sh`로 넣으므로 화면이나 셸 기록에 남지 않습니다.

## 5. 당일 운영

### 강의실 배치

- 앞쪽 스크린: 강사 화면 (터미널 글꼴 크게: Windows Terminal `Ctrl + =`)
- 조교는 줄 사이 통로에. 학생은 **체크포인트 카드**(초록/빨강 포스트잇)를 노트북 뒤에 붙임: 초록 = 통과, 빨강 = 도움 필요
- 조교용 공유 메모: 자주 나온 오류와 해결을 실시간으로 적고, 쉬는 시간에 전체 공지

### 시간 관리

각 모듈 자료의 시간표대로 가되, **절반 이상이 체크포인트를 통과하면** 다음으로 넘어갑니다.
늦어진 학생이 뒤 모듈을 따라올 수 있도록 각 모듈은 앞 모듈의 결과물 없이도 시작할 수 있게 되어 있습니다.

| 늦어진 학생이 | 이렇게 이어서 |
|---|---|
| 모듈 2에서 지도를 못 만듦 | 제공 지도로 `navigation.launch.py` (기본값) |
| 모듈 3에서 MoveIt 실습을 못 끝냄 | `bringup.launch.py` + `pick_place_demo`는 독립 실행 |
| 모듈 4에서 API 키 문제 | `planner:=true llm:=scripted` |
| 노트북이 너무 느림 (`simulation is slower` 경고) | `use_viewer:=false`, RViz 대신 대시보드만, 옆 사람과 짝 실습 |

### 강사 시연 팁

- 시연 전에 `ros2 service call /mujoco_bridge/reset std_srvs/srv/Trigger`로 월드 리셋
- 최종 미션은 약 80초. 그동안 대시보드의 타임라인을 짚으며 "지금 Claude가 무엇을 골랐는지" 설명
- 실패도 좋은 교재입니다: 실패 메시지를 Claude가 읽고 다음 계획을 바꾸는 장면을 보여 주기

## 6. 비상 대응

### 설치를 끝내지 못한 학생 (당일)

**오프라인 설치본**: 설치가 끝난 Ubuntu를 통째로 내보내 USB로 나눠 줄 수 있습니다.

강사 PC에서 (미리, 깨끗한 배포판으로 `install_unbolt.sh`를 끝낸 상태에서):

```powershell
PS> wsl --shutdown
PS> wsl --export Ubuntu-22.04 D:\unbolt-wsl.tar        # 약 10 GB
```

학생 PC에서 (WSL 자체는 설치되어 있어야 함 — `wsl --install --no-distribution` 후 재부팅):

```powershell
PS> wsl --import Ubuntu-22.04 C:\WSL\Ubuntu-22.04 E:\unbolt-wsl.tar
PS> wsl -d Ubuntu-22.04 -u root -- bash -c "printf '[user]\ndefault=student\n' >> /etc/wsl.conf"
PS> wsl --terminate Ubuntu-22.04
```

(`student`는 강사 PC에서 만든 리눅스 사용자 이름. 내보낸 파일에 강사의 API 키(`~/.unbolt_key`)가 들어가지 않게
**내보내기 전에 삭제**하세요.)

### 그 밖에

| 상황 | 대응 |
|---|---|
| 강의실 와이파이가 느림 | 설치는 사전에 끝났으므로 실습에는 인터넷이 거의 필요 없음 (모듈 4의 API 호출만). 휴대폰 핫스팟 예비 |
| API 장애 | 모듈 4를 `llm:=scripted`로 진행하고 실제 Claude는 나중에 각자 |
| WSL이 노트북에서 아예 안 됨 (회사 노트북 정책 등) | 짝 실습. 또는 [README](README.md)의 Ubuntu 22.04 노트북 안내 |
| 노트북 메모리 8 GB에서 모듈 3~4가 멈춤 | `.wslconfig` (설치 가이드 2-4), `use_viewer:=false rviz:=false` + 대시보드 |
